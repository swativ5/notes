# Object Recognition and Detection

## Object Recognition
- computer vision task that involves identifying and classifying objects within an image or video.
- task: given an image x, does x contatin an object of class y?
- applications: image search, medical imaging, facial recognition, autonomous vehicles, and robotics.

## Object Detection
- computer vision task that involves not only identifying, classifying objects and determining their locations within an image or video.
- pinpoint the location of the object in the image, often by drawing a bounding box around it.
- subset of object recognition
- applications: surveillance systems, driverless vehicles, retail analytics, medical imaging, quality control.

## Bounding Box Representations
- Top-left corner (x1, y1) and bottom-right corner (x2, y2) 
- Top/center (x_top/x_center, y_top/y_center) and width (w) and height (h)

## Why is recognition hard?
- Variability in object appearance: objects can look different due to changes in lighting, pose, occlusion, and background clutter.
- Intra-class variability: objects of the same class can have significant variations in shape, size, and color.
- Inter-class similarity: different classes of objects can look similar, making it difficult to distinguish between them.

## Approaches for Human Detection
- Haar Cascades by Viola and Jones:
    - uses haar-like features & capture differences in image intensity
    - adaboost algorithm to select the most relevant features and create a strong classifier
    - cascade of classifiers to quickly reject non-human regions and focus on potential human regions   
    - main requirements: dicriminate face/non-face, fast detection
    - limitations: sensitive to variations in lighting, pose, and occlusion

- ada boost helps you choose the best features and combine them into a strong classifier
    - combination of weak classifiers to create a strong classifier

- cascade classifier: series of classifiers that are applied sequentially to an image region. Each classifier is designed to quickly reject non-human regions, allowing the system to focus computational resources on potential human regions.
    - early stages: simple classifiers that quickly reject non-human regions
    - later stages: more complex classifiers that focus on potential human regions, improving accuracy while maintaining efficiency.

- Histogram of oriented gradients (HOG):
    - feature descriptor used for object detection, particularly in human detection.
    - calculate the distribution of gradient orientations in local images
    - svm used to classify the features extracted by HOG
    - more robust to variations in lighting and pose compared to haar cascades 
    - struggles with occlusion and complex background
    - Steps:
        - find magnitude and direction of gradients for each pixel in the image
        - divide the image into cells of same size (cell size is a hyperparameter)
        - group the gradient directions of all pixels in a cell into a speciifed number of orientation bins
        - group the cells into larger block (2x2) of same size. (stride is the amount of movement of block window across the image)
        - normalize the histogram of each block to account for changes in illumination and contrast

    - Gx = I(x+1,y) - I(x-1,y)
