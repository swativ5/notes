# Feature Dectection & Matching

- Feature Detection algorithms:
    - Identufy interesting, unique descriptive features to detect the objects.
    - Match them and recognize the objects
    - Applications:
        - Image Stiching: align the two images so that they can be seamelessly stiched into a composite mosaic
        - Object recognition: Identifying specific objects within an image by comparing extracted features to a know database of object features
        - Image registration: aligning two or more images if the same scene taken at different times, angles, or sensors (used in medical imaging, remote sensing, computer vision and robotics)
        - 3D construction: to establish a dense set of correspondences so that a 3D model can be constructed or an in-between view can be generated
        - Object tracking: object tracking, feature detection & matching is used to identify and lcate key points on an object across multiple frames

- Feature: a piece of informationw which is relevant for solving the computational task related to a certain application
    - Main categories:
        - Key point/interest point/ corner featues: peaks, corner. appearance of patch of pixels surrounding the point location
        - Edges (object boundaries): matched based on their orientation and local appearance (edge profiles) and can also be good indicators of object boundaries and occlusion events in image sequences

- Main components of Feature detection and matching
    - Identify the interest point
        - point at which the direction of the boundary of the object changes abruptly.
        - properties:
            - well defined position or well localised
            - stable under local and global perturbations in teh image domain
            - should provide efficient detection
                - interest point has rich image content within local window
        - possible appriaches:
            - based on the brightness of an image
            -based on boundary extraction
        - Algorithm for identification of interest point:
            - Harris Corner detector
            - Scale Invariant Feature Transform - SIFT
            - Speeded Up Robust Features - SURF
            - Features from Accelerated Segment test - FAST
            - Oriented FAST and Roatated Brief - ORB
    - Decription: the local appearance around each feature point is decribed in some way that is invariant under changes in illumination, translation, scale and in-plane rotation
        - gives descriptor vector for each interest point
        - Feature descriptor:
            - an algoritm whicht akes an image and outputs feature descriptors/ feature vectors
            - Decriptor classes:
                - Local Descriptor: Local decriptors cature features from specific regions or points within an image. they focus on small patches of images and describe them in a way that is invariant to certain transformations
                - GLobal decriptor: summarize the entire image as a single feature bector, capturing overall characteristics rather than local deatils. like color histrogram which applied to the whole image
                - Algorithms used:
                    - SIFT, SURF, BRISK (Binary Robust Invariant Scalabe Keypoints,), BRIEF (BInary Robust Independent Feature...), ORB
    - Matching: descriptors are compared across the images to identify similar featues
        - set of pairs of matching features
        - task of establishing correspondences betwenn two images of the same scene/ object

## SIFT Detector and Feature Descriptor
 Scale Invariant Feature Transform - SIFT

- used for image alignment and 2D object recognition
- Extracting distinct inavriant features
    - correctly matched against a large DB of features of many images
- invariance to image scale and rotation
- robustness to 
    - affine distortion
    - change in 3D viewpoint
    - addition of noise
    - change in illumination
- Advantages:
    - locality: features are local, so robust to occlusion and clutter
    - distinctiveness: individual features can be matched to a large dn
    - quantity: many features can be generated or even small objects
    - efficiency: cllose to real-time performance
- Main steps:
    - Detecting interest points:
        - edges, corners, peaks
        - detect blobs, pathes with a local appearance
