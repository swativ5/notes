# Word Embeddings
- Word embeddings are a type of word representation in NLP that allows words to be represented as vectors in a continuous vector space.
- they are numerical reprsentations of words that capture their semantic meaning and relationships with other words.

### Distributional representation
- Any word wi in the corpus is given a distributional representation by an embedding wi ∈ Rd, where d is the dimension of the embedding space.
- take a vector with several hundred dimensions (say 1000)
- each word is represnted by a distribution of weights across these dimensions...
- If we label the dimensions in a hypothetical word vector, such a vector comes to represent in some abstract way the "meaning" of the word.

#### Reasoning with Word Vectors
- It has been found that learned word representation in fact capture meaningful semantic relationships between words.
- Specifically, the regularities are observed as constant vector offsets between pairs of words that share a particular relationship.
- It might be good at answering analogy questions:
    - a is to be, as c is to ? (a:b :: c:d)
        - d = arg max [(wb - wa + wc)T wx / ||wb - wa + wc|| ]
        - where wx is the embedding of different words in the corpus x
    - man is to women, uncle is to ? (aunt) 

### Represent the meaning of word - word2vec
- there are two main approaches to learning word embeddings:
    - continous bag of words (CBOW)
        - given context words, predict the target word
        - \<context\> \<target\> \<context\>
    - skip-gram
        - given a target word, predict the context words
        - \<target\> \<context\> \<target\> 

#### CBOW
- the context words form the input layer. each word is encoded in one-hot form. a single hidden and output layer. 
- the training objective is to maximize the probability of the target word given the context words with regards to the weights.
- input layer: one-hot encoding of context words (1 x v)
- weight matrix w1: v x n
- hidden (1 x n) = (1 x v) x (v x n)
- given C input word vectors, the activation fucntion for the hidden layer h ammounts to simply summing the corresponding 'hot' rows in w1 and dividing by C (the number of context words) to get the average.
- w2: n x v
- output layer: softmax function to predict the target word
- the weight matrix is the word embedding in word2vec. each row of weight matrix becomes the embedding of the corresponding word in the vocabulary.

|CBOW|Skip-gram|
|-|-|
|predicts the target word from the context word| predicts the context word from the target word|
| good results on large context| works even with small context|
| fast to train| slower to train|

### Limitations of word2vec
- out of vocabulary (OOV) problem: word2vec can only learn embeddings for words that appear in the training corpus. it cannot handle new words that are not present in the training data. (even if tensor, flow was in the corpus, it will not be able to handle tensorflow)
- morphology: word2vec treats each word as a distinct entity, which means that it does not capture the morphological structure of words. for example, the words "run", "running", and "runner" would be treated as separate entities, even though they share a common root.

# Evaluation Metrics
- Accuracy = (TP + TN) / (TP + TN + FP + FN)
- Precision = TP / (TP + FP)
- Recall (Sensitivity) = TP / (TP + FN)
- Specificity = TN / (TN + FP)
- F1 Score = 2 * (Precision * Recall) / (Precision + Recall)
- Fn Score = (1 + n^2) * (Precision * Recall) / (n^2 * Precision + Recall)
- Bilingual Evaluation Understudy (BLEU) Score: evaluates the quality of machine-generated text by comparing it to one or more reference translations. it is commonly used in machine translation tasks.
    - n gram overlap between the generated text and reference translations
    - BLEU score ranges from 0 to 1, where a higher score indicates better quality.
- Rouge Score (Recall-Oriented Understudy for Gisting Evaluation): evaluates the quality of machine-generated text by comparing it to one or more reference summaries. it is commonly used in text summarization tasks.
    - measures the overlap of n-grams between the generated summary and reference summaries
    - Rouge score ranges from 0 to 1, where a higher score indicates better quality.
- METEOR Score: evaluates the quality of machine-generated text by comparing it to one or more reference translations. it is designed to address some of the limitations of BLEU and Rouge scores.
    - considers synonymy, stemming, and paraphrasing in addition to n-gram overlap
    - METEOR score ranges from 0 to 1, where a higher score indicates better quality.
- BERTScore: evaluates the quality of machine-generated text by comparing it to one or more reference texts using contextual embeddings from the BERT model. it is designed to capture semantic similarity between the generated text and reference texts.
    - uses cosine similarity between BERT embeddings of the generated text and reference texts
    - BERTScore ranges from 0 to 1, where a higher score indicates better quality.
